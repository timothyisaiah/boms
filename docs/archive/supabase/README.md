# Retired Supabase migration history

These SQL files preserve the legacy BOMS schema and permission history, including
unapplied local changes present at retirement. They are archival references only.
All current migrations, reference data, and provisioning live under `neon/` and
`scripts/`; never apply these files to Neon or resume the old Supabase workflow.

The private retirement backup under `.backups/supabase-2026-09-12/` contains the
original source tree and legacy environment configuration. Database exports and
verification details are recorded in [the retirement record](../../supabase-retirement.md).
